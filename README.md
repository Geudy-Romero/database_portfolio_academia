# Database Portfolio - Academia

Este repositorio contiene los ejercicios y proyectos que voy realizando durante mi formación en el **Máster de Conquer Blocks**, relacionados con bases de datos y SQL utilizando **MySQL**.

Aquí voy guardando lo que voy aprendiendo y poniendo en práctica, desde consultas básicas hasta la creación de bases de datos con sus respectivas tablas y relaciones.

## Tecnologías

- MySQL
- SQL

## Temas trabajados

Algunos de los conceptos que he ido aprendiendo y practicando son:

- Creación de bases de datos y tablas.
- Claves primarias y foráneas (Primary Keys y Foreign Keys).
- Restricciones como NOT NULL, UNIQUE y CHECK.
- Inserción, actualización y eliminación de datos.
- Consultas SELECT y filtros con WHERE.
- Relaciones entre tablas utilizando JOIN.
- Funciones para trabajar con fechas.
- Creación de índices.
