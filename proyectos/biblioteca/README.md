# Proyecto: Base de datos de biblioteca

Este proyecto consiste en crear una base de datos para gestionar una pequeña biblioteca utilizando **MySQL**.

Permite registrar libros y usuarios, llevar un control de los préstamos y consultar la disponibilidad de los libros.

## Conceptos trabajados

- Creación de bases de datos y tablas.
- Claves primarias y foráneas.
- Restricciones y valores predeterminados.
- Inserción y actualización de datos.
- Consultas SQL utilizando `SELECT` y `WHERE`.
- Relaciones entre tablas mediante `INNER JOIN`.
- Funciones de fechas como `DATEDIFF`.
- Creación de índices.

## Tecnologías utilizadas

- MySQL
- SQL

## Archivo del proyecto

El archivo `biblioteca.sql` contiene el código utilizado para crear y trabajar con la base de datos.
